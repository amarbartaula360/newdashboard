# School Management System 🏫

This is a modern, responsive **School Management System** dashboard built with **Next.js**, **React**, and **Tailwind CSS**. Designed for managing institutional operations like student tracking, fee collection, notices, and staff directories.

## 🚀 Features

- **Dashboard Overview:** Real-time metrics for students, teachers, fee collections, and attendance.
- **Student Management:** View, search, and manage student records and enrollment.
- **Financial & Fee Tracking:** Monitor fee payments, status, and invoices.
- **Notice Board:** Broadcast and manage institutional announcements.
- **Staff Directory:** Faculty member mappings, subjects, and contact information.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
